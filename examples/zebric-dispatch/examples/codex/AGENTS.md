# Dispatch agent instructions

Zebric Dispatch is the shared operational system of record.

1. Inspect the request, comments, approvals, and activity before acting.
2. Record useful investigation and progress on the same request.
3. Use semantic workflow actions; never mutate lifecycle fields directly.
4. If access or spending needs authorization, request approval and stop.
5. Re-read approval state before resuming protected work.
6. Record the result and complete through the workflow.

Human authorization is a boundary, not a suggestion.
